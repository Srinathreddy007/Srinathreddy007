**Django · Sentence-Transformers · pgvector · HNSW · Faster-Whisper · FFmpeg · REST APIs**

Built end to end as a software engineer at NYU. Transcribes video with Faster Whisper, embeds with Sentence Transformers, indexes in pgvector via HNSW — enabling natural language, timestamp-level retrieval across a large video archive. Serves 10,000+ active users at sub-500ms query latency.
